# 中文标准库

## 一、它是什么

`zhstdlib\` 是随编译器一起发的**中文头目录**（119 个头），通过 `<驱动名>.cfg` 自动进入搜索路径。
写 `#包含 <向量>` 就等价于 `#include <vector>`，但命名空间和常用 API 都有中文名。

```cpp
#包含 <C标准输入输出>
#包含 <向量>

整数 主函数() {
    标准::向量<整数> 表;
    表.尾插(10);
    表.尾插(20);
    标准::格式化输出("表长 = %d，第二个 = %d\n", (整数)表.尺寸(), 表[1]);
    返回 0;
}
```

```
表长 = 2，第二个 = 20
```

## 二、`#包含 <向量>` 凭什么不用 `-I`

靠**编译器同目录的 `<驱动名>.cfg`**（clang 的配置文件机制）：

```
bin\chinese++.cfg        ← 以 chinese++.exe 启动时读它
bin\clang++.cfg          ← 以 clang++.exe 启动时读它
bin\clang.cfg            ← clangd 的回落驱动读它（不写这份，编辑器会把中文头标红）
```

内容形如：

```
-isystem
"E:/.../toolchains/cpp/zhstdlib"
-isystem
"E:/.../toolchains/cpp/zhstdlib/标准库"
-isystem
"E:/.../toolchains/cpp/zhstdlib/别名"
-isystem
"E:/.../toolchains/cpp/zhstdlib/C运行库"
-isystem
"E:/.../toolchains/cpp/zhstdlib/windows系统"
```

要点（都是踩出来的）：

- cfg 里**反斜杠是转义符** ⇒ 路径必须用**正斜杠**；
- cfg 的行**按空白分词** ⇒ 含空格的路径必须**加引号**；
- **相对路径不可靠** ⇒ 只能写绝对路径 ⇒ 所以**移动目录 / 换安装位置之后必须重跑生成**。

## 三、生成 / 修复 cfg

```powershell
# 仓库构建树
pwsh -File E:\Chinese++\tools\make_zhcfg.ps1

# 发行包 / 安装目录（<包根> 是含 bin\ 与 zhstdlib\ 的那层）
pwsh -File <包根>\install.ps1
```

`make_zhcfg.ps1` 从单一事实来源 `tools\zh_includes.ps1` 生成，**不要手改 cfg**。

## 四、九个二进制名也要在

clang 的驱动模式**按程序名后缀**决定（`++` 结尾即 g++ 模式），所以下列名字是必要的：
`clang.exe`、`clang++.exe`、`clang-cl.exe`、`clang-cpp.exe`、`lld.exe`、`ld.lld.exe`、
`wasm-ld.exe`、`llvm-lib.exe`、`llvm-ranlib.exe`。

发行包是 ZIP，**不保留硬链接**，所以解压后这些名字会丢 —— 必须跑一次安装脚本重建。

**症状**：`bin\` 里只有 `chinese++.exe` / `clangd.exe`，`verify.ps1` 直接打印
`This package has NOT BEEN SET UP YET.` 并退出。

## 五、中文头里有什么

| 目录 | 内容 |
|---|---|
| `zhstdlib\` | 入口头（`C标准输入输出`、`向量`、`字符串` …） |
| `zhstdlib\标准库\` | 标准库的中文对应 |
| `zhstdlib\别名\` | 别名层（同一个实体的第二个中文名） |
| `zhstdlib\C运行库\` | C 运行库头 |
| `zhstdlib\windows系统\` | Windows 相关头 |

三条实现轨道（详见 `docs\标准库汉化\标准库汉化方案.md`）：**深度复制** / **别名** / **转发**。
共同铁律：不改变语义、不破坏 `#include` 英文路径、不引入与 MSVC 的 ABI 差异。

## 六、查名字的方法

```powershell
# 中文头里到底有没有这个名字
Get-ChildItem <包根>\zhstdlib -Recurse -File | Select-String -Pattern '尾插' | Select-Object -First 5

# 让编译器把真实搜索路径与解析过程打出来
chinese++ -std=c++20 -H -fsyntax-only 你的.cpp
chinese++ -x c++ -E -v -
```

> **写不出某个中文名时，直接用英文**：英文永远可用，且永远不会被"按名字改写"。
