## 它就是能用

```cpp
#包含 <C标准输入输出>
#包含 <向量>

整数 主函数() {
    标准::向量<整数> 表;
    表.尾插(10);
    表.尾插(20);
    标准::格式化输出("表长 = %d，第二个 = %d\n", (整数)表.尺寸(), 表[1]);
    返回 0;
}
```

```text
表长 = 2，第二个 = 20
```

## 凭什么不用 `-I`？

```text
        chinese++ -std=c++20 你好.cpp
                    │
                    ▼
        ┌───────────────────────────┐
        │ 读编译器同目录的 cfg       │   bin\chinese++.cfg
        │ （clang 的配置机制）       │   bin\clang++.cfg
        └───────────┬───────────────┘   bin\clang.cfg  ← clangd 读它
                    │
                    ▼
        -isystem "…/zhstdlib"
        -isystem "…/zhstdlib/标准库"
        -isystem "…/zhstdlib/别名"
        -isystem "…/zhstdlib/C运行库"
        -isystem "…/zhstdlib/windows系统"
```

> [!IMPORTANT]
> **cfg 里是绝对路径** ⇒ 移动目录 / 换安装位置之后**必须重跑生成**。

<details>
<summary><b>cfg 文件长什么样（实测内容）</b></summary>

```text
-isystem
"E:/…/toolchains/cpp/zhstdlib"
-isystem
"E:/…/toolchains/cpp/zhstdlib/标准库"
-isystem
"E:/…/toolchains/cpp/zhstdlib/别名"
-isystem
"E:/…/toolchains/cpp/zhstdlib/C运行库"
-isystem
"E:/…/toolchains/cpp/zhstdlib/windows系统"
```

三个坑（都是踩出来的）：

| 坑 | 规则 |
|---|---|
| 反斜杠 | cfg 里是**转义符** ⇒ 路径必须用**正斜杠** |
| 分词 | cfg 按**空白**分词 ⇒ 含空格的路径必须**加引号** |
| 相对路径 | 不可靠 ⇒ 只能写**绝对路径** |

</details>

## 生成 / 修复

```powershell
# 构建树（仓库里）
pwsh -File E:\Chinese++\tools\make_zhcfg.ps1

# 发行包 / 安装目录（推荐：它同时会建别名）
pwsh -File <包根>\install.ps1
```

> [!NOTE]
> `make_zhcfg.ps1` 从单一事实来源 `tools\zh_includes.ps1` 生成，**不要手改 cfg**。

## 顺带：9 个二进制名

clang 的驱动模式**按程序名后缀**决定（`++` 结尾 ⇒ g++ 模式），所以这些名字是必需的：

```text
clang.exe  clang++.exe  clang-cl.exe  clang-cpp.exe
lld.exe    ld.lld.exe   wasm-ld.exe
llvm-lib.exe  llvm-ranlib.exe
```

发行包是 ZIP，**不保留硬链接** ⇒ 解压后这些名字会丢。

> [!WARNING]
> **症状**：`bin\` 里只有 `chinese++.exe` / `clangd.exe`，`verify.ps1` 直接打印
> `This package has NOT BEEN SET UP YET.` 然后退出。

## 中文头里有什么

| 目录 | 内容 |
|---|---|
| `zhstdlib\` | 入口头（`C标准输入输出`、`向量`、`字符串` …） |
| `zhstdlib\标准库\` | 标准库的中文对应 |
| `zhstdlib\别名\` | 别名层（同一实体的第二个中文名） |
| `zhstdlib\C运行库\` | C 运行库头 |
| `zhstdlib\windows系统\` | Windows 相关头 |

<details>
<summary><b>三条实现轨道</b></summary>

| 轨道 | 做法 | 用在哪 |
|---|---|---|
| 深度复制 | 复制上游头并把名字换成中文 | 需要完整独立实现的 |
| 别名 | 保留上游实现，加一层中文名 | 大多数标准库设施 |
| 转发 | `#include` 指回上游头 | 只需要中文名字的 |

共同铁律：**不改变语义**、不破坏英文 `#include`、不引入与 MSVC 的 ABI 差异。
详见 `docs\标准库汉化\标准库汉化方案.md`。

</details>

## 查名字的方法

```powershell
# 中文头里到底有没有这个名字
Get-ChildItem <包根>\zhstdlib -Recurse -File | Select-String '尾插' | Select-Object -First 5

# 让编译器交代解析过程
chinese++ -std=c++20 -H -fsyntax-only 你的.cpp
chinese++ -x c++ -E -v -
```

> [!TIP]
> **写不出中文名时直接用英文** —— 英文永远可用，而且永远不会被"按名字改写"。
