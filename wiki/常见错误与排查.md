# 常见错误与排查

## 一、报错对照表

| 你看到的 | 真正的意思 | 怎么办 |
|---|---|---|
| `fatal error: 找不到文件（名字） '向量'` | 中文头没进搜索路径 | ① 检查 `bin\*.cfg` 是否存在；② 检查 9 个别名是否齐；③ 重跑安装脚本 |
| `This package has NOT BEEN SET UP YET.` | `verify.ps1` 发现别名缺失 | 跑 `install.ps1`（发行包）或安装器（CDZC） |
| `（关键字） 大小 不能用作标识符；要当名字请换一个词` | 你拿关键字当标识符了 | 换个词（`尺寸`/`长度`）或用英文 |
| `'main' 必须返回（关键字） 整数` | 入口写成了 `空型 主函数()` | 改成 `整数 主函数()`（C 里写 `整数 主函数(空型)`） |
| `-std=c17` 报错（编 `.c` 时） | `chinese++` 默认是 **C++ 模式** | 加 `-x c`：`chinese++ -x c -std=c17 文件.c` |
| `找不到文件（名字）'C标准输入输出'`，但 `-I` 加上就好了 | 典型"包没装完" | 同上，重跑安装脚本 |
| 满屏 `warning C4996 ... fopen ...` | MSVC 头的弃用警告 | 加 `-D_CRT_SECURE_NO_WARNINGS`，或示例任务已默认加了 |
| 中文头在编辑器里标红，但命令行能编 | clangd 没读到 `clang.cfg` | 确认 `bin\clang.cfg` 存在（不是只有 `chinese++.cfg`） |
| 换目录后全崩 | cfg 里是**绝对路径** | 重跑 `make_zhcfg.ps1` / 安装脚本 |

## 二、一条命令自检

```powershell
pwsh -File <包根>\verify.ps1
```

29 项，全部 `[ok]` 才算装好。它会检查：

- 5 个真身 + 9 个别名是否都在；
- VC++ 运行时 DLL（`msvcp140` / `vcruntime140` / `vcruntime140_1`）是否随包；
- 中文标准库能否**不带任何 `-I`/`-isystem`** 找到；
- `<vector>` 到底来自**包内**还是**本机 Visual Studio**（对应 `bin\toolchain.txt` 里的 `mode`）；
- `mode = bundled|system` 是否合法。

## 三、环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10/11 x64 |
| **C++ 编译** | 需要 **Visual Studio Build Tools / Windows SDK**（当前 `mode = system`） |
| 中文头 | 随包提供（`zhstdlib\`），不需要另装 |
| 编辑器 | 任意；用 clangd 可获得中文关键字不标红的体验 |

> **`bundled`（不依赖 Visual Studio）目前还没做完**：设成 bundled 时，
> `verify.ps1` 会查出仍有 Windows SDK 头来自 `C:\Program Files (x86)\Windows Kits\…`。

## 四、看编译器到底在找哪些目录

```powershell
# 完整搜索路径（最有用）
chinese++ -x c++ -E -v -

# 谁 include 了谁、每个头解析到哪个真实文件
chinese++ -std=c++20 -H -fsyntax-only 你的.cpp
```

第一条命令的输出里应该出现 5 条 `zhstdlib` 路径；没有就是 cfg 没生效。

## 五、我自己踩过的错（写出来免得你重复）

| 我写的 | 正确 | 原因 |
|---|---|---|
| `整数 主函数(空型)` 编 `.cpp` | `整数 主函数()` | C++ 的 `main` 不写参数也行；带 `空型` 是 C 的形态 |
| `整` | `整数` | 没有 `整` 这个关键字 |
| `空` | `空型` | 同上 |
| `打印格式` | `标准::格式化输出` | 没有这个中文名 |
| `表.大小()` | `表.尺寸()` | `大小` 是 `sizeof` 的关键字 |
