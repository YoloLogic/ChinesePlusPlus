## 一条命令先自检

```powershell
pwsh -File <包根>\verify.ps1
```

```text
29 passed, 0 failed -- this package works.
```

看到 `0 failed` 就不用往下读了 —— 环境是好的，问题在你的代码。

## 报错对照表

| 严重度 | 你看到的 | 真正的意思 | 怎么办 |
|:---:|:---|:---|:---|
| 🔴 | `fatal error: 找不到文件（名字） '向量'` | 中文头没进搜索路径 | 查 `bin\*.cfg` 是否存在 → 查 9 个别名 → 重跑安装脚本 |
| 🔴 | `This package has NOT BEEN SET UP YET.` | 别名缺失 | 跑 `install.ps1` / 安装器 |
| 🟠 | `（关键字） 大小 不能用作标识符；要当名字请换一个词` | 拿关键字当标识符了 | 换词（`尺寸`/`长度`）或用英文 |
| 🟠 | `'main' 必须返回（关键字） 整数` | 入口写成了 `空型 主函数()` | 改成 `整数 主函数()`（C 里 `整数 主函数(空型)`） |
| 🟠 | 编 `.c` 时 `-std=c17` 报错 | `chinese++` 默认 **C++ 模式** | 加 `-x c` |
| 🟡 | 满屏 `warning C4996 … fopen …` | MSVC 头的弃用警告 | 加 `-D_CRT_SECURE_NO_WARNINGS` |
| 🟡 | 编辑器里中文头标红，命令行能编 | clangd 没读到 `clang.cfg` | 确认 `bin\clang.cfg` 存在（不只 `chinese++.cfg`） |
| 🔴 | 换个目录后全崩 | cfg 里是**绝对路径** | 重跑 `make_zhcfg.ps1` / 安装脚本 |

## 排查流程

```text
中文头找不到？
   │
   ├─ bin\chinese++.cfg 存在吗？ ──否──▶ 跑安装脚本（生成 cfg）
   │            │是
   ├─ 9 个别名齐吗？ ──否──▶ 跑 install.ps1（重建别名）
   │            │是
   ├─ chinese++ -x c++ -E -v -  的输出里有 5 条 zhstdlib 吗？
   │            │有
   └─ ✅ 环境没问题 → 看是不是写错了名字（关键字不能当标识符）
```

## 看编译器到底在找哪些目录

```powershell
# 完整搜索路径（最有用）
chinese++ -x c++ -E -v -

# 谁 include 了谁、每个头解析到哪个真实文件
chinese++ -std=c++20 -H -fsyntax-only 你的.cpp
```

第一条命令的输出里**应该出现 5 条 `zhstdlib` 路径**；没有就是 cfg 没生效。

## 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10/11 x64 |
| **C++ 编译** | **不需要装任何东西**（包内 `bundled` 底座自带 STL 头、SDK 头、导入库、运行时 DLL） |
| 中文头 | 随包提供（`zhstdlib\`） |
| 编辑器 | 任意；用 clangd 可获得中文关键字不标红 |

> [!TIP]
> **`bundled` 就是默认值**：`make_zhcfg.ps1 -Mode bundled` 生成的 cfg 带 `-nostdinc`，
> 所有头文件与导入库都指向包内，`verify.ps1` **29 项全过**。

<details>
<summary><b>我自己踩过的 5 个错（写出来免得你重复）</b></summary>

| 我写的 | 正确 | 原因 |
|---|---|---|
| `整数 主函数(空型)` 编 `.cpp` | `整数 主函数()` | 带 `空型` 是 C 的形态 |
| `整` | `整数` | 没有这个关键字 |
| `空` | `空型` | 同上 |
| `打印格式` | `标准::格式化输出` | 没有这个中文名 |
| `表.大小()` | `表.尺寸()` | `大小` 是 `sizeof` 的关键字 |

</details>
