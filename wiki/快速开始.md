## 1️⃣ 装

### 🅰️ 随「中文大战代码」安装包（推荐）

下载 [CDZC 安装程序](https://github.com/YoloLogic/CDZC/releases) → 双击 → 装完即用。

```text
<安装目录>\toolchains\cpp\
├── bin\chinese++.exe        ← 编译器（Clang 驱动，g++ 模式）
├── bin\clangd.exe           ← 语言服务器（给编辑器用）
├── bin\clang.exe            ┐
├── bin\clang++.exe          │
├── bin\clang-cl.exe         │ 9 个二进制别名
├── bin\clang-cpp.exe        │ （ZIP 不保留硬链接，必须重建）
├── bin\lld.exe              │
├── bin\ld.lld.exe           │
├── bin\wasm-ld.exe          │
├── bin\llvm-lib.exe         │
├── bin\llvm-ranlib.exe      ┘
├── bin\chinese++.cfg        ← 中文头搜索路径（绝对路径！）
├── bin\clang++.cfg          ← 同上
├── bin\clang.cfg            ← clangd 读这份，缺了编辑器会标红
└── zhstdlib\                ← 119 个中文头
```

> [!NOTE]
> 安装器会自动建好 **9 个别名** + 写好 **3 份 cfg**。这两件事就是"开箱能编中文头"的全部秘密。

### 🅲 VS Code 扩展（已有 VS Code，不想装整套发行版）

装 **汉语编程 · 中文 C++** 扩展即可 —— 编译器随扩展一起下载，**不需要 Visual Studio / Build Tools**：

```text
https://marketplace.visualstudio.com/items?itemName=YoloLogic.chinese-plus-plus
```

也可从 [GitHub Release](https://github.com/YoloLogic/chinese-plus-plus-vscode/releases) 下 `.vsix`，
用 `Extensions: Install from VSIX…` 安装。装完新建 `你好.cpp`，按 <kbd>Ctrl</kbd>+<kbd>F5</kbd>。

### 🅱️ 独立发行包

`Chinese++-0.3-win64.zip`（约 101 MB）→ 解压 → 双击 **`一键安装.cmd`**。

> [!WARNING]
> 移动或改名过文件夹，必须**再跑一次安装** —— cfg 里是绝对路径。

## 2️⃣ 写

**C++** — `你好.cpp`

```cpp
#包含 <C标准输入输出>

整数 主函数() {
    标准::格式化输出("你好，汉语 C++！\n");
    返回 0;
}
```

**C** — `你好.c`

```c
#包含 <C标准输入输出>

整数 主函数(空型) {
    标准::格式化输出("你好，汉语 C！\n");
    返回 0;
}
```

> [!IMPORTANT]
> **C 的 `main` 要写 `整数 主函数(空型)`**，并且编译时加 `-x c`。

## 3️⃣ 编

```powershell
# C++ —— 不需要任何 -I / -isystem
chinese++ -std=c++20 你好.cpp -o 你好.exe
.\你好.exe

# C —— 必须显式切到 C 模式
chinese++ -x c -std=c17 你好.c -o 你好.exe
.\你好.exe

# 只看诊断，不产出文件
chinese++ -std=c++20 -fsyntax-only 你好.cpp
```

```text
你好，汉语 C++！
```

## 4️⃣ 在编辑器里

1. 打开 `examples\cpp\` 目录
2. 按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> → 选「C++：编译并运行」
3. 终端里已继承工具链 <code>PATH</code>（由 `cdzc-toolchains` 扩展注入，**不改系统环境**）

> [!TIP]
> 示例任务里**没有** `-I` —— 中文头由 `bin\*.cfg` 提供。

## 5️⃣ 自检（一条命令）

```powershell
pwsh -File <安装目录>\toolchains\cpp\verify.ps1
```

```text
29 passed, 0 failed -- this package works.
```

<details>
<summary><b>这 29 项到底查什么？</b></summary>

| 组 | 检查 |
|---|---|
| 文件 | 5 个真身 + 9 个别名是否都在 |
| 运行时 | `msvcp140` / `vcruntime140` / `vcruntime140_1` 是否随包 |
| 中文头 | 能否**不带任何 `-I`/`-isystem`** 找到 |
| 底座 | `<vector>` 究竟来自**包内**还是**本机 VS**（对应 `bin\toolchain.txt` 的 `mode`） |
| 模式 | `mode = bundled|system` 是否合法 |

</details>

## 6️⃣ 命令速查

| 想干的事 | 命令 |
|---|---|
| 编 C++20 | `chinese++ -std=c++20 文件.cpp -o 文件.exe` |
| 编 C17 | `chinese++ -x c -std=c17 文件.c -o 文件.exe` |
| 只看诊断 | `chinese++ -std=c++20 -fsyntax-only 文件.cpp` |
| 看每个头解析到哪 | `chinese++ -std=c++20 -H -fsyntax-only 文件.cpp` |
| 看完整搜索路径 | `chinese++ -x c++ -E -v -` |
| 关掉 MSVC 弃用警告 | 加 `-D_CRT_SECURE_NO_WARNINGS` |
