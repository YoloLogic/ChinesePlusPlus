# 快速开始

## 一、装（两种方式）

### 方式 A：随「中文大战代码」安装包（推荐）

下载 **CDZC 安装程序**（[Releases](https://github.com/YoloLogic/CDZC/releases)），装完后：

```
<安装目录>\toolchains\cpp\bin\chinese++.exe      编译器
<安装目录>\toolchains\cpp\bin\clangd.exe         语言服务器
<安装目录>\toolchains\cpp\zhstdlib\              中文头（119 个）
```

安装器会自动建好 **9 个二进制别名**（`clang.exe`/`clang++.exe`/`clang-cl.exe`/`clang-cpp.exe`/
`lld.exe`/`ld.lld.exe`/`wasm-ld.exe`/`llvm-lib.exe`/`llvm-ranlib.exe`）
并写好 **5 份 `<驱动名>.cfg`**（中文头搜索路径）——这两件事是"开箱能编译中文头"的前提。

**要求**：本机需要 **Visual Studio Build Tools / Windows SDK**（MSVC 的 STL 与 UCRT）。
当前发行版用 `mode = system`，"不依赖 Visual Studio"的自足底座还没做完。

### 方式 B：独立发行包

`Chinese++-0.3-win64.zip` → 解压 → 双击 **`一键安装.cmd`**。
它会建别名、写 `env.cmd`、检测 VS Build Tools、写入 `bin\*.cfg`、并跑一遍包内自测。

> ⚠ 移动过文件夹就要**再跑一次安装**（cfg 里是绝对路径）。

## 二、写第一个程序

`你好.cpp`：

```cpp
#包含 <C标准输入输出>

整数 主函数() {
    标准::格式化输出("你好，汉语 C++！\n");
    返回 0;
}
```

**写 C 的话**要注意 `main` 的签名（C 的 `main` 必须返回 `整数` 且无参形态要写 `空型`）：

```c
#包含 <C标准输入输出>

整数 主函数(空型) {
    标准::格式化输出("你好，汉语 C！\n");
    返回 0;
}
```

## 三、编译运行

```powershell
# C++（不需要任何 -I / -isystem）
chinese++ -std=c++20 你好.cpp -o 你好.exe
.\你好.exe

# C（必须显式指定语言模式，否则 chinese++ 默认按 C++ 解析）
chinese++ -x c -std=c17 你好.c -o 你好.exe
.\你好.exe
```

> **`chinese++` 默认是 C++ 模式**（驱动模式由程序名后缀决定，`++` 结尾即 g++ 模式）。
> 编 `.c` 文件请加 `-x c`，否则 `-std=c17` 会报错。

## 四、在编辑器里用

随 CDZC 安装的编辑器里：

1. 打开 `examples\cpp\` 目录；
2. 按 **Ctrl+Shift+B** 选「C++：编译并运行」；
3. 终端与任务已经继承了工具链 PATH（由 `cdzc-toolchains` 扩展注入，不改系统环境）。

任务里**不需要**手写 `-I`——中文头由 `bin\*.cfg` 提供。

## 五、一条命令自检

```powershell
pwsh -File <安装目录>\toolchains\cpp\verify.ps1
```

**29 项全过**才算"装好了"（它同时检查：别名齐不齐、VC++ 运行时 DLL、中文标准库能否**不带 `-I`** 找到、
`<vector>` 来自包内还是本机 VS、`toolchain.txt` 的 mode 是否合法）。

## 六、命令行速查

| 想干的事 | 命令 |
|---|---|
| 编 C++20 | `chinese++ -std=c++20 文件.cpp -o 文件.exe` |
| 编 C17 | `chinese++ -x c -std=c17 文件.c -o 文件.exe` |
| 只看诊断不看产物 | `chinese++ -std=c++20 -fsyntax-only 文件.cpp` |
| 看头文件从哪来 | `chinese++ -std=c++20 -H -fsyntax-only 文件.cpp` |
| 看完整搜索路径 | `chinese++ -x c++ -E -v -` |
| 用 clangd（IDE） | 把 `bin` 加进 PATH，编辑器用 clangd 即可（它读同一份 cfg） |
