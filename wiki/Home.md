# Chinese++ · 汉语 C/C++ 编译器

> **不是创新的汉语编程，却是最强的汉语编程。**

Chinese++ 是 **Clang/LLVM 的 fork**：把中文关键字做成**第一公民**，同时**英文照旧可用**，
两者完全等价 —— 共用同一套 C++ 生态（标准库、第三方库、调试器、clangd 全都继续用）。

```cpp
#包含 <C标准输入输出>

整数 斐波那契(整数 n) {
    如果 (n <= 1) { 返回 n; }
    返回 斐波那契(n - 1) + 斐波那契(n - 2);
}

整数 主函数() {
    标准::格式化输出("斐波那契(10) = %d\n", 斐波那契(10));
    返回 0;
}
```

## 你能得到什么

| 能力 | 说明 |
|---|---|
| 中文关键字 | 控制流、类型、运算符、预处理指令都能写中文；**中英可混写** |
| 中文诊断 | 七千多条报错正文译成中文（`error: 找不到文件（名字） '向量'`） |
| 中文标准库 | `zhstdlib\` 提供 `#包含 <向量>` `<C标准输入输出>` 这类中文头，`标准::` 命名空间 |
| 与 MSVC 二进制兼容 | 同一份 C++ 生态，既有库照常链接 |
| clangd 同步 | 语言服务器用同一套关键字表，中文关键字在 IDE 里也不标红 |

## 一句话边界（先看这个，少踩坑）

- **关键字**用中文 ✓；`main` **必须**写成 `整数 主函数`（返回类型得是 `整数`）；
- 中文关键字**不能当标识符**（例如 `大小` 是 `sizeof` 的关键字，不能做方法名）；
- C++ 用 `整数 主函数()`；**写 C 要用 `整数 主函数(空型)`** 并以 C 模式编译（`-x c`）；
- 中文头靠**编译器同目录的 `<驱动名>.cfg`**（绝对路径）⇒ **移动目录后要重跑生成**；
- 诊断正文是中文，但来自 **MSVC 头文件**的 `note:` 仍是英文（那是微软的头，不是我们的）。
