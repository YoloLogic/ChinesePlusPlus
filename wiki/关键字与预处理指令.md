## 三条设计原则

```text
① 中文关键字是第一公民   →  改在词法/语法层，不是翻译层
② 中英等价、可随意混写   →  同一文件里 如果 / if 并存没问题
③ 不改变语义             →  中文写法与英文写法编出的目标码一致
```

## 命名规则：最容易踩的一条

中文关键字**不能当标识符**。和英文同一规则（`if` 也不能当变量名）。

```cpp
// ❌ 报错：（关键字） 大小 不能用作标识符
整数 大小() { 返回 1; }

// ✅ 换个词
整数 尺寸() { 返回 1; }

// ✅ 或者直接英文
int size() { return 1; }
```

程序入口有条固定要求：

```cpp
整数 主函数() { 返回 0; }   // ✅ C++
空型 主函数() { }           // ❌ 'main' 必须返回（关键字） 整数
```
