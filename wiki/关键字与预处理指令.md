# 关键字与预处理指令

## 一、设计原则

1. **中文关键字是第一公民**：不是"翻译层"，是编译器词法/语法层直接认识；
2. **中英完全等价、可以混写**：同一个文件里 `如果` 和 `if` 并存没问题；
3. **不改语义**：写法和英文写法编出来的目标码一致。

## 四、运算符

| 中文 | 英文 |
|---|---|
| `与` / `或` / `非` | `&&` / `||` / `!` |
| `并且` / `并非` | `and` / `not`（替代记号） |
| `位与` / `位或` / `异或` | `&` / `|` / `^` |
| `不等于` | `!=` |
| `大小` | `sizeof` |
| `此` | `this` |

> ⚠ **`大小` 是关键字**，所以 `表.大小()` 会报
> `（关键字） 大小 不能用作标识符；要当名字请换一个词`。
> 想给方法取名请换词（例如 `尺寸`/`长度`），或用英文 `size()`。

## 五、预处理指令（22 条，可与英文混用）

| 中文 | 英文 |
|---|---|
| `#包含` | `#include` |
| `#定义` | `#define` |
| `#如果` / `#否则` / `#否则若` / `#结束如果` | `#if` / `#else` / `#elif` / `#endif` |
| `#如果已定义` / `#如果未定义` | `#ifdef` / `#ifndef` |
| `#警告` | `#warning` |
| `#错误` | `#error` |
| `#行` | `#line` |
| `#编译指示` | `#pragma` |
| `#取消定义` | `#undef` |

实测：`#警告` 打出来的也是**中文警告**。

## 六、命名规则（最容易踩的一条）

**中文关键字不能被拿来当标识符。** 命名时先看这张表里有没有你的词：

```cpp
// ✗ 报错：（关键字） 大小 不能用作标识符
整数 大小() { 返回 1; }

// ✓ 换一个词
整数 尺寸() { 返回 1; }

// ✓ 或者用英文
int size() { return 1; }
```

程序入口也有一条固定要求：

```cpp
整数 主函数() { 返回 0; }     // ✓ C++
空型 主函数() { }             // ✗ 'main' 必须返回（关键字） 整数
```
