一、这是一个【修改过的】LLVM/Clang（重要）
------------------------------------------

本发行包里的 clang / lld / clangd / llvm-* 二进制，是由 **修改过的 LLVM 源码**
构建的，不是上游原版。依据 Apache License 2.0 第 4(b) 条，我们在此明确声明：
**我们改动了若干 LLVM/Clang 源文件。**

改动内容（完整清单见 docs\关键字\关键字改动清单.md 与 patches\*.patch）：

  * 新增中文关键字拼写表（99 个），英文拼写一律保留、行为不变
  * 新增中文预处理指令拼写表（22 条），与英文等价、可混用
  * 新增中文诊断正文表（7344 / 7374 条），查不到时回退英文
  * 让 `主函数` 与 `main` 成为同一个标识符

改动**不涉及**任何 `Diagnostic*.td`：那 17 个文件与上游逐字节相同。
所有改动都以补丁形式保存在 patches\ 下。

上游项目：https://llvm.org/  （LLVM 24.0.0git）

四、包里装了什么
----------------

  bin\chinese++.exe     C++ 编译器（中文为主，英文照旧可用）
  bin\clang.exe         C 编译器（与上面是同一个程序，靠文件名分派）
  bin\clang-cl.exe      MSVC 风格命令行
  bin\clang-cpp.exe     仅预处理（-E）
  bin\clangd.exe        语言服务（编辑器高亮与补全用）
  bin\lld-link.exe      Windows 链接器
  bin\lld.exe / ld.lld.exe / wasm-ld.exe
  bin\llvm-ar.exe / llvm-lib.exe / llvm-ranlib.exe
  bin\llvm-rc.exe       Windows 资源编译器
  bin\*.dll             10 个 Visual C++ 运行时库（见第七节）
  lib\clang\24\include\ 编译器内建头文件（stddef.h / stdint.h 等）
  lib\clang\24\lib\windows\  compiler-rt 运行时（见第六节）
  lib\stl\              开源版 MSVC STL 头（见第七节）
  lib\mingw\            mingw-w64 的 UCRT + Win32 头（见第七节）
  lib\crt\  lib\compiler\  我们自己的 CRT / 导入库 / 编译器支持头
  zhstdlib\             中文标准库（119 个头）

  ※ 上面若干 `.exe` 是**同一个程序的硬链接**。若复制或解压后硬链接丢失，
    会变成多份独立副本（功能不受影响，只是占用变大）。
    安装脚本会用 New-Item -ItemType HardLink 重建。


五、包里【没有】装什么
----------------------

  1. **微软的 Windows SDK 库与 MSVC 工具链本体**（cl.exe、Windows SDK 的 .lib/.h 全集）。
     本包自带一套**可再分发的基底**（第七节）足以开箱即用；
     若要切到"用本机 Visual Studio"的 system 模式，请自行安装 Visual Studio Build Tools。
  2. **Visual Studio Code 编辑器本体**（默认包不打包，安装脚本按需从官网下载到包内 .\vscode\，
     便携模式，不动你已有的 VS Code）。
  3. **不是**微软官方产品，与 Microsoft 无隶属或背书关系。


六、compiler-rt 运行时：**已包含**
----------------------------------

  lib\clang\24\lib\windows\ 内含 compiler-rt 运行时（12 个文件）。
  因此 `-fsanitize=address`、`-fsanitize=undefined`、`--coverage` 等**可用**，
  包内自检（verify.ps1）会真编真跑并核对它们确实报出问题。


七、包里带的第三方（以及微软可再分发的部件）
--------------------------------------------

  这些**不是**本项目的版权，各按各的许可，逐文件来源与 SHA256 见 MANIFEST.txt：

  1. **开源版 MSVC STL 头**（lib\stl\，176 个文件）
     来源：microsoft/STL（开源仓库），许可：Apache-2.0 with LLVM Exceptions。
     我们**没有再分发**微软随 Visual Studio 发行的 STL 头，用的是开源仓库那一份。

  2. **mingw-w64 的 UCRT + Win32 头**（lib\mingw\，2037 个文件）
     来源：mingw-w64 项目，许可：多为 public domain 或 MIT 类（以各文件头为准）。

  3. **Visual C++ 运行时库 DLL**（bin\*.dll，10 个：msvcp140*.dll / vcruntime140*.dll /
     concrt140.dll / vccorlib140.dll 等）
     来源：Microsoft Visual C++ **可再分发**运行库，按其**再分发条款**随包附带（app-local）。
     它们让"开箱即用"成立：不需要你机器上先装 Visual Studio 就能跑起来。
     这些 DLL 的著作权属微软，适用微软自己的许可条款。

  4. 其余（lib\crt\、lib\compiler\、zhstdlib\、tools\、二进制）见第二、三节。
