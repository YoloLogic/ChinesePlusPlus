# Chinese++ 教学教程 —— 从零学会写汉语 C++

> 这本教程教你三件事：**汉语关键字怎么用**（每个都给出对应的英文）、
> **原本那套符号怎么用**（`{}` `()` `;` `::` `->` … 一个没换）、
> **基础标准库怎么用**（`#包含 <向量>`、`标准::向量<整数>` …）。
>
> 它只讲汉语化带来的差异与够用的基础，**不替代 C++ 教材**。
>
> **本文件是生成物，不要手改。** 由 `tools\make_tutorial_cpp.ps1` 把
> `教程\例子\*.cpp` 的真源码与「期望输出」切进 `教程\教程模板.md` 生成。
> `tools\check_tutorial_cpp.ps1` 会**真编译真运行**每个例子并核对输出，
> 同时核对本文件与例子是否逐字一致 —— 所以教程里的代码**必然能跑**。

## 怎么用这本教程

1. 先读「第 0 课」把编译命令跑通。
2. 每课都有一份**能直接编译运行**的例子，放在 `教程\例子\`。
3. 例子开头的注释里写了它自己的**期望输出** —— 你跑出来的应当一模一样。
4. 汉语写法和英文写法**可以混着写**，同一行里混都行。学会汉语不等于扔掉英文。

## 第 1 课 程序骨架

### 本课关键字

| 汉语 | 英文 | 干什么 |
|---|---|---|
| `整数` | `int` | 整数类型；`整数 主函数()` 里的 `主函数` 是 `main` 的汉语名 |
| `主函数` | `main` | 程序入口。**和 `main` 是同一个标识符**，写哪个都行，但不能两个都写 |
| `空型` | `void` | 「什么也不返回」 |
| `返回` | `return` | 从函数返回 |
| `#包含` | `#include` | 把另一个文件的内容引进来 |

### 本课符号

| 符号 | 名称 | 用法 |
|---|---|---|
| `{ }` | 花括号 | 包住一段代码（函数体、类体、分支体）。**成对出现** |
| `( )` | 圆括号 | 包住函数参数表；调用函数时也是它 |
| `;` | 分号 | **每条语句末尾必须有**（函数体、类体、`#` 行末尾不写） |
| `::` | 双冒号 | 名域/类型限定：`标准::标准输出流` = `std` 里的 `cout` |
| `" "` | 双引号 | 字符串字面量 |
| `' '` | 单引号 | 单个字符字面量（第 2 课用） |
| `#` | 井号 | 预处理指令的开头，**必须在一行最前面**（可以缩进） |
| `//` | 行注释 | 从这里到行尾都不算代码 |

## 第 3 课 运算符与符号

**本课最重要的一句话：符号一个都没换。** 汉语化增加的是关键字的另一种拼写，
不是把 `+ - * /` 换成汉字。唯一的例外是 11 个「运算符替代拼写」——
它们本来就是英文 `and` / `or` / `not` 那一族的等价物。

### 本课关键字（运算符替代拼写）

| 汉语 | 等价英文 | 等价符号 |
|---|---|---|
| `并且` | `and` | `&&` |
| `或者` | `or` | `\|\|` |
| `并非` | `not` | `!` |
| `不等于` | `not_eq` | `!=` |
| `位与` | `bitand` | `&` |
| `位或` | `bitor` | `\|` |
| `异或` | `xor` | `^` |
| `取反` | `compl` | `~` |
| `与赋值` | `and_eq` | `&=` |
| `或赋值` | `or_eq` | `\|=` |
| `异或赋值` | `xor_eq` | `^=` |

### 本课符号

| 类别 | 符号 | 说明 |
|---|---|---|
| 算术 | `+` `-` `*` `/` `%` | `%` 是取余 |
| 比较 | `==` `!=` `<` `>` `<=` `>=` | 结果是 `1`（真）或 `0`（假） |
| 赋值 | `=` `+=` `-=` `*=` `/=` `%=` | `甲 += 1` 等价 `甲 = 甲 + 1` |
| 自增自减 | `++` `--` | 前置后置都照写 |
| 逻辑 | `&&` `\|\|` `!` | 也可以写 `并且` `或者` `并非` |
| 位运算 | `&` `\|` `^` `~` `<<` `>>` | 也可以写 `位与` `位或` `异或` `取反` |
| 三元 | `? :` | `条件 ? 真时取值 : 假时取值` |

## 第 4 课 分支与循环

### 本课关键字

| 汉语 | 英文 | 干什么 |
|---|---|---|
| `如果` / `否则` | `if` / `else` | 分支 |
| `选择` | `switch` | 多分支 |
| `情形` | `case` | 选择里的一个分支 |
| `默认` | `default` | 选择里的兜底分支 |
| `对于` | `for` | 计次循环 / 范围遍历 |
| `每当` | `while` | 先判断再执行 |
| `执行` | `do` | 先执行一次再判断（搭配 `每当` 收尾） |
| `跳出` | `break` | 结束整个循环 |
| `跳过` | `continue` | 跳过本轮剩下的 |

### 本课符号

| 写法 | 说明 |
|---|---|
| `如果 (条件) { … }` | 条件必须用 `( )` 包起来 |
| `如果 … 否则 { … }` | `否则` 前**不写分号** |
| `选择 (值) { 情形 1: … 跳出; 默认: … }` | `情形` 后面是**冒号**，每个 `情形` 末尾要 `跳出` |
| `对于 (初值; 条件; 步进) { … }` | 三段用**分号**隔开 |
| `执行 { … } 每当 (条件);` | `do-while`：末尾那个 `每当` 后面必须有 `;` |
| `对于 (自动 项 : 容器) { … }` | 范围遍历，`:` 读作「在…里」 |

## 第 5 课 函数

### 本课关键字

| 汉语 | 英文 | 干什么 |
|---|---|---|
| `空型` | `void` | 不返回值 |
| `返回` | `return` | 返回值 / 提前结束 |
| `自动` | `auto` | 让编译器推返回类型 |
| `常量` | `const` | 只读参数 |

### 本课符号（这一课的符号最关键）

| 符号 | 位置 | 含义 |
|---|---|---|
| `( )` | 函数名后 | 参数表；空着表示没有参数 |
| `,` | 参数之间 | 分隔参数 |
| `&` | **类型后**：`整数& 甲` | **引用**：函数里改的就是外面那个变量 |
| `&` | **变量前**：`&值` | **取地址**：把变量的地址交出去 |
| `*` | **类型后**：`整数* 指针` | **指针**类型 |
| `*` | **指针前**：`*指针` | **解引用**：取出它指向的那个值 |
| `->` | 指针后 | 用指针访问成员 |
| `::` | 名域后 | 限定到某个名域/类型 |

> 一句话记住：**`&` 和 `*` 在类型那边是「是什么」，在变量那边是「取什么」。**

## 第 6 课 自己定义类型

### 本课关键字

| 汉语 | 英文 | 干什么 |
|---|---|---|
| `类型` | `class` | 定义类型（**注意：不是「类」**，汉语关键字一律不少于两个字） |
| `结构` | `struct` | 默认成员公开的类型 |
| `枚举` | `enum` | 枚举 |
| `公开` / `私有` / `受保护` | `public` / `private` / `protected` | 访问说明符 |
| `自身` | `this` | 指向当前对象 |
| `虚拟` | `virtual` | 允许派生类改写 |
| `重写` | `override` | 声明「我在改写基类的虚函数」 |
| `最终` | `final` | 到此为止，不许再被继承/改写 |
| `静态` | `static` | 属于类型本身，不属于某个对象 |
| `新建` / `删除` | `new` / `delete` | 动态分配 / 释放 |
| `使用` | `using` | 引进名字 / 起别名 |
| `类型别名` | `typedef` | 起类型别名（老写法） |

### 本课符号

| 写法 | 说明 |
|---|---|
| `类型 名字 { … };` | 类体末尾**必须有分号** |
| `公开:` | 访问说明符后面是**冒号**，不是分号 |
| `类型 派生 : 公开 基类 { … };` | 继承：冒号 + 访问说明符 + 基类名 |
| `.` | 用**对象**访问成员：`甲.面积()` |
| `->` | 用**指针**访问成员：`指针->说()` |
| `::` | 类名后限定：`人::数量`、`整数 人::数量 = 0;` |

## 第 8 课 基础标准库

汉语标准库的规矩很简单：**头名有汉语的，类型名与成员名也有一套汉语的，
而英文原名照旧可用**。

| 东西 | 汉语写法 | 英文写法（照旧可用） |
|---|---|---|

| 类型 | `标准::向量<整数>` | `std::vector<int>` |
| 成员 | `数.尾插(4)` | `数.push_back(4)` |

### 本课指令（英文对照）

| 汉语 | 英文 | 干什么 |
|---|---|---|
| `#包含` | `#include` | 引入头文件 |
| `#定义` | `#define` | 定义宏 |

| `< >` | `#包含 <向量>` 尖括号：系统头 |
| `" "` | `#包含 "我的头.h"` 双引号：自己写的头 |

## 附录 A 符号用法速查

**这张表要背下来的只有一句话：符号一个都没换。**
汉语化只让**关键字**多了汉语拼写；下面这些符号在汉语代码里照旧。

| 符号 | 名字 | 典型写法 | 别忘的事 |
|---|---|---|---|
| `//` | 行注释 | `// 说明` | 到行尾 |
| `/* */` | 块注释 | `/* 多行 */` | 不能嵌套 |
| `#` | 井号 | `#包含 <向量>` | 按行生效，末尾不写分号 |
| `;` | 分号 | `返回 0;` | 每条语句末尾 |
| `{ }` | 花括号 | `整数 主函数() { … }` | 成对；类体末尾还要分号 |
| `( )` | 圆括号 | `如果 (甲 > 乙)`／`打招呼()` | 条件、参数、调用都用它 |
| `[ ]` | 方括号 | `数[0]`／`整数 表[10];` | 下标**从 0 开始** |
| `.` | 点 | `甲.面积()` | 用**对象**访问成员 |
| `->` | 箭头 | `指针->说()` | 用**指针**访问成员 |
| `::` | 双冒号 | `标准::向量`／`人::数量` | 名域/类型限定 |
| `< >` | 尖括号 | `标准::向量<整数>`／`模板 <类型名 T>` | 模板参数 |
| `" "` | 双引号 | `"你好"` | 字符串 |
| `' '` | 单引号 | `'A'` | 单个字符 |
| `\` | 反斜杠 | `"\n"`／`"引号\"里面"` | 转义 |
| `,` | 逗号 | `相加(3, 4)` | 分隔参数/声明多个变量 |
| `=` | 等号 | `整数 甲 = 1;` | 赋值；**比较要写 `==`** |
| `==` `!=` | 相等/不等 | `甲 == 乙` | 结果是 1 或 0 |
| `<` `>` `<=` `>=` | 大小比较 | `甲 >= 60` | 结果是 1 或 0 |
| `+` `-` `*` `/` `%` | 算术 | `甲 % 2` | `%` 取余 |
| `+=` `-=` `*=` `/=` | 复合赋值 | `甲 += 1` | 等价 `甲 = 甲 + 1` |
| `++` `--` | 自增自减 | `甲++`／`--甲` | 前置后置都可 |
| `&&` `\|\|` `!` | 逻辑 | `真 && 假` | 也可写 `并且` `或者` `并非` |
| `&` `\|` `^` `~` `<<` `>>` | 位运算 | `6 & 3` | 也可写 `位与` `位或` `异或` `取反`；`<<` 还兼做流插入 |
| `&` | 引用/取地址 | `整数& 甲`／`&值` | 在类型那边是引用，在变量那边是取地址 |
| `*` | 指针/解引用 | `整数* 指针`／`*指针` | 同上 |
| `? :` | 三元 | `甲 > 乙 ? 甲 : 乙` | 条件 ? 真值 : 假值 |

## 附录 C 常见坑

| 坑 | 现象 | 怎么办 |
|---|---|---|
| 单字关键字不存在 | 写 `类` 编不过 | 汉语关键字**不少于两个字**：`class` 是 `类型`，不是 `类`（见对照表） |
| `最大` ≠ `最大值` | 写 `标准::最大` 报「没有名为 最大 的成员」 | 按用法表查真名：是 `最大值` / `最小值` |
| 有些成员只有英文名 | 写 `名.查找` 报错 | 用英文 `名.find(...)`；英文永远可用 |
| 汉语头 vs 英文头 | 只 `#include <string>` 却用 `标准::字符串` | 想要汉语名字就 `#包含 <字符串>` |
| `标准::字符串` 数的是字节 | `"你好"` 的 `尺寸()` 是 6 不是 2 | 按字节算；要按字符算得用宽字符或 UTF-8 库 |
| 引用的 `&` 忘了写 | 函数里改了，外面没变 | 参数写 `整数&` 才是引用 |
| `情形` 忘了 `跳出` | 会把后面的分支也执行了 | 每个 `情形` 末尾写 `跳出` |
| `执行…每当` 末尾忘分号 | 编译错 | `执行 { … } 每当 (条件);` |

## 那，英文怎么办？

**照样用，而且可以混着写。** 例如下面这行完全合法：

```cpp
标准::向量<std::string> 混合 = {"汉语名字", "英文名字"};
```

汉语不是替换英文，是**并行多出来的一种拼写**。
这也是为什么「随便拿一个开源 C++ 项目，用我们的编译器编，照样编得过」。
