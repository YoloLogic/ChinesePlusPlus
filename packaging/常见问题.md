# 使用前必读 / 常见问题

> 这一份是给使用者看的。**动手之前请先看完第一节。**

---

## 一、最重要的一条：必须先装 Visual Studio

**本工具链不自带标准库。** 你需要先装 Visual Studio（或 Build Tools），
并且**勾上 C++ 开发组件**。

### 为什么

C++ 标准库（`std::vector`、`std::string`…）、C 运行库、Windows SDK
都是**微软的东西**，我们没有权利把它们打包分发。

所以本包只含**编译器自己**（clang / lld / clangd 等，约 75 MB），
标准库要用你机器上已有的那份。

**这也是一件好事**：正因为用的是微软原封不动的 MSVC STL，
用本编译器编出来的东西和用官方 clang / VS 编出来的**完全二进制兼容**，
可以互相链接 —— 现成的第三方库照用。

### 没装会怎样

```
$ chinese++ 你好.cpp -o 你好.exe
你好.cpp:1:10: fatal error: 找不到文件（名字） 'cstdio'
```

**看到"找不到文件"这类错误，十有八九就是这一条。**

### 怎么装

用 winget（Windows 10/11 自带）：

```powershell
winget install --id Microsoft.VisualStudio.2022.BuildTools --override "--quiet --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
```

或者去官网下载 **Visual Studio Community**（免费），安装时勾选
**「使用 C++ 的桌面开发」**。

> **大小与时间**：下载约 2 GB，装完约占 6 GB，需要几分钟。
> 装它需要管理员权限。

## 二、安装的时候要联网

`一键安装.cmd` 会做这些需要网络的事：

| 做什么 | 大小 |
|---|---|
| 下载官方 Visual Studio Code | 约 320 MB |
| 装中文语言包扩展 | 小 |
| 装 clangd 扩展 | 小 |

**如果网断了**：重新双击一次 `一键安装.cmd` 就行。
已经装好的部分不会重装，中断的部分会重来。**不需要先删掉什么。**

## 三、关于编辑器，你要知道的四件事

1. **界面是中文的**，但**第一次打开才生效**（安装时只是把语言包装好了）。
2. **用的是便携模式**：编辑器的设置和扩展都留在这个文件夹里。
3. **不会碰你自己装的那个 VS Code** —— 一个字节都不动。
4. **装完提示的最后一行会告诉你下一步**：启动哪个 `Code.exe`、
   打开哪个文件夹、按什么键编译。

## 四、常见问题

### Q：编译报 `找不到文件 'cstdio'` / `'vector'`

**没装 Visual Studio，或者装的时候没勾 C++ 组件。** 见第一节。

想确认装没装好，在包里运行：

```powershell
powershell -File verify.ps1
```

它会真编一个中文 hello world。**过了就是能用。**

### Q：编辑器里满屏红波浪，但明明能编过

**clangd 用错了。** clangd 扩展默认会自己下载一个**官方 clangd**，
那个不认识中文关键字（`类型`、`返回`、`如果` 全被当成未定义）。

检查 `examples\.vscode\settings.json` 里这一行，必须指向**本包内**的 clangd：

```json
"clangd.path": "……\\bin\\clangd.exe"
```

### Q：编辑器界面还是英文

中文语言包没装上（可能装的时候没网）。手动装：
按 `Ctrl+Shift+X` 打开扩展面板，搜 `Chinese`，装
**Chinese (Simplified) Language Pack**，然后重启编辑器。

### Q：为什么 `std::vector`、`.push_back()` 还是英文

**因为标准库我们没有改名。** 中文覆盖的是**语言本身**（关键字、预处理指令、
报错信息），库的名字和成员函数保持原样。

改名会切断生态 —— 详见 `中文对照表.md` 第五节。

### Q：报错前缀为什么是英文的 `error:`，正文才是中文

**故意的。** 编辑器的问题面板和 CI 脚本靠 `error:` / `warning:` 这个前缀
抓日志，翻成「错误:」它们就抓不到了。

### Q：忘了写 `main`，报一堆链接错误

```
LINK : fatal error LNK1561: 必须定义入口点
```

这就是没写入口函数。入口点可以写 `main`，**也可以写 `主函数`**：

```cpp
整数 主函数() { 返回 0; }   // 等价于 int main() { return 0; }
```

### Q：中文报错没出现，还是英文

诊断正文汉化了 7344 / 7374 条（99.6%）。极少见的诊断会回退英文。
另外 `-fno-chinese-diagnostics` 可以主动切回英文。

### Q：能调试吗

**能。** 编辑器是官方 VS Code，市场里的 C/C++ 扩展可用（断点、变量、调用栈）。
按 `F5`；第一次会让你选环境，选 **C++ (Windows)**。

### Q：怎么卸载

**直接删掉这个文件夹就行。** 我们没往系统里写任何东西 ——
没改 PATH（除非你显式加了）、没写注册表、没动你已有的 VS Code。

想要会话级的命令行环境：双击 `env.cmd`，它只影响那一个窗口。

### Q：我能把这个文件夹挪到别处 / 搬到 U 盘吗

**能，但装完之后搬的话，要再双击一次 `一键安装.cmd`。**

原因是这样：

- **脚本本身没有硬编码路径** —— 它们靠「自己的位置」推导一切（`$PSScriptRoot` /
  `%~dp0`），所以整个文件夹搬到任何盘符都能跑。
- **但编辑器配置里必须是绝对路径**。安装时 `examples\.vscode\settings.json`
  和 `tasks.json` 里的 `@@CLANGD@@` / `@@CXX@@` 会被替换成**当时**的真实路径，
  因为 clangd 扩展不认相对路径，也不展开 VS Code 变量。

所以搬完之后再双击一次 `一键安装.cmd` 就行 —— **它只改那两处路径，几秒钟，
已经装好的编辑器、扩展都不会重装。**

## 五、想让**你自己的** VS Code 也用上 Chinese++

上面安装的是包内那个**便携版**编辑器，它和你的 VS Code 互不干扰。

如果你希望**平时用的那个 VS Code** 也认中文关键字，运行：

> ### `一键装配到我的VSCode.cmd`

它做三件事：

1. **先备份**你的用户设置：
   `%APPDATA%\Code\User\settings.json` → `settings.json.zhpp-backup`
2. 往设置里加两项：`clangd.path` 指向**本包内的** clangd（官方那个不认中文关键字），
   以及 `clangd.arguments`（含 `--query-driver`，用来找到 MSVC STL 与 Windows SDK）
3. 如果你的 VS Code 还没装 clangd 扩展，帮你装上

**它不会**：动包内的便携版、动你设置里的其它内容、卸载任何东西。

### 怎么还原

> ### `一键还原我的VSCode.cmd`

它把 `settings.json` **从备份原样恢复**（不是删掉几个键，是整份还原）。
如果你原本**没有** `settings.json`，它会把我们创建的那个删掉。

> **注意**：还原**不会**卸载 clangd 扩展 —— 你可能想留着。
> 不想留就在扩展面板里自己移除。

## 六、这个文件夹里都是什么

| 文件/目录 | 是什么 |
|---|---|
| **`一键安装.cmd`** | **先跑这个**。装好本包并自测 |
| **`一键装配到我的VSCode.cmd`** | 让**你自己的** VS Code 也认中文（可还原） |
| **`一键还原我的VSCode.cmd`** | 把上面的改动**原样撤销** |
| `env.cmd` | 双击得到一个能用 `chinese++` 的命令行窗口（只影响那个窗口） |
| `bin\` | 编译器本体：`chinese++.exe`、`clang.exe`、`clangd.exe`、`lld-link.exe` 等 |
| `lib\clang\24\include\` | 编译器的内建头文件（`stddef.h`、`stdint.h` 等），**必须随包** |
| `vscode\` | 安装后才出现：便携版编辑器 |
| `examples\` | 中文示例 + 编辑器配置。**在编辑器里打开这个文件夹** |
| `中文对照表.md` | 99 个关键字 + 22 条指令 + 入口点的完整对照 |
| `LICENSE.TXT` / `NOTICE.txt` | 许可证（LLVM 是 Apache-2.0 with LLVM Exceptions） |
| `MANIFEST.txt` | 这个包里到底装了什么、每个文件的校验值 |
| `verify.ps1` | 自测。想确认能不能用就跑它 |
| `install.ps1` / `attach-to-vscode.ps1` / `detach-from-vscode.ps1` | 上面那几个 `.cmd` 背后的逻辑，**一般不用直接跑** |
