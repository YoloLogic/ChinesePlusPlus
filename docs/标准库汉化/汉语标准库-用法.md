## 一、三句话学会用

1. **头名用汉语**：`#包含 <向量>`。只写它，`标准::向量<整数>` 与 `std::vector<int>` 同时可用
   —— 后者是微软原件，一个字节没动（铁律 ①）。
2. **中文在前、英文在后**：`标准::向量<整数>::值类型` 与 `::value_type` 都对。
3. **两个类型不互通**：`标准::向量` 与 `std::vector` 布局相同但是**两种类型**，不能直接互相传参
   —— 这是"实现本身是汉语的"必须付的代价，详见方案 §16.29.3。

另有可编译的完整示例：`examples\汉语库示例.cpp`（它是总判据的一部分，必须整体编过）。

## 五、Windows 系统 API（3 个：给 Win32 名字加一层中文名）

这一节的头**不是标准库头**：源头是系统 SDK（`windows.h`），那些名字住在**全局名域**，
所以别名没有 `std::` 前缀，函数用同一条转发模板直接调 Win32 原名。

三条注意（每条都有实测判据，见方案 §3.4.2）：

1. **一律指向显式的 `…W` 真函数**：Win32 里 `CreateFile` / `WriteConsole` / `GetModuleHandle`
   这类"函数"其实是宏，宏会被展开、不能转发。
2. **产品头自己兜住 `NOMINMAX` 与 `WIN32_LEAN_AND_MEAN`**：不给它们，`windef.h` 的 `min/max`
   宏与 `rpcndr.h` 的 `byte` 会拆坏标准库头（组合探针实测各 20 条错）。
3. **只加名字，不改行为**：值宏直接引 SDK 自己的宏（`STD_OUTPUT_HANDLE` 等），不重写定义。
