## 三、一条铁律：搬文件是改接口

本项目已经为这条付出过三次代价（`#include` 相对路径、脚本按旧名找文件、文档里的路径失效）。
所以**移动或改名任何文档后**，必须做两件事：

```powershell
# 1) 找出所有引用（把旧的文档名填进去）
Get-ChildItem E:\Chinese++ -Recurse -Include *.md,*.ps1,*.py,*.cpp,*.def,*.td |
  Select-String '旧的文档名'

# 2) 逐个改：文档里的链接、脚本注释、C++ 注释，以及
#    LLVM-main\clang\include\clang\Basic\ChineseDiagnostics.def（它在注释里引用了术语表）
```

> ⚠️ `ChineseDiagnostics.def` 里若改了东西，**必须重编 + 重新生成补丁**：
> 它是编译器源码（被 `Diagnostic.cpp` include），改了就会进 `zh-diagnostics.patch`。
