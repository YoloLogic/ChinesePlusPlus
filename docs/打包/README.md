## 一句话结论（详见上面两份）

分发一个 C++ 编译器，真正的难点**不在我们的东西**（编译器 78 MB + 内建头 8 MB +
clangd 45 MB ≈ 130 MB），而在**别人的东西**：Windows 上 C++ 标准库和链接器
都来自 Visual Studio，合起来约 **1 GB**。

所以"要不要替用户把这一份也带上"是唯一的大决策。而**先做「一键配置」是最划算的第一步**：
它绕开了这 1 GB，直接命中中文编程真正的卖点。
