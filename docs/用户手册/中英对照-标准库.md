## 五、怎么用

同一件事的两种写法，编译结果等价：

```cpp
// 中文
#包含 <向量>
标准::向量<整数> 表;
表.尾插(1);
```

```cpp
// 英文（原名照旧可用）
#include <vector>
std::vector<int> v;
v.push_back(1);
```
