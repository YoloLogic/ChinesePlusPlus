## 库用法对照表

`docs\用户手册\中英对照-标准库.md`（同时生成一份到 `packaging\`，随包发）。

三部分：

1. **头文件对照**（119 条）：`向量` → `<vector>`、`类型特征` → `<type_traits>`
2. **类型与别名对照**（约 248 条）：`真类型` = `std::true_type`、`世界协调时钟` = `std::chrono::utc_clock`
3. **成员函数对照**（约 820 条，按头分组）：`尾插` = `push_back`、`尺寸` = `size`
   内部实现名（`_向量值` = `_Vector_val` 等）折叠在 `<details>` 里，读源码时用。

### 这张表是怎么来的（可复现）

中文侧 `zhstdlib\` 是英文母本 `vendor\msvc-stl\`（或 `vendor\mingw\`）的**逐行翻译**，
所以：

- 行号**不能**用来配对（注释翻译会改变行数：`向量` 4065 行 vs `vector` 3988 行）
- 但**函数定义的出现顺序**保留，签名在抹掉标识符后也保留

做法：把每行函数定义归一化（`_Xxx` 与中文标识符都抹平、函数自身名字也抹掉），
用 `difflib` 按签名序列对齐，**只接受签名相等的一对**。试过两种更省事的办法，都
会出错并已弃用：

| 办法 | 结果 |
|---|---|
| 直接按行号配对 | 行数不同，整体错位 |
| 纯顺序 zip | 会漂移（`相邻差` 曾配到 `constexpr`）|
| 只按签名查唯一候选 | `size`/`capacity`/`empty` 签名相同，多候选全丢 |

极短名（`尺寸`/`容量`/`清空`）仍会漏，用一张**手工核对补丁表**补，且生成时做
「两侧都存在 + 参数个数相同」两道机器校验，不过就丢。

### 实证

`docs\用户手册\中英对照-标准库.md` 里的映射被编译器验证过：同一段逻辑写中英两版，
用发行包里的 `chinese++.exe` 编译，**输出逐字节相同**（`尺寸`/`容量`/`尾插`/`尾删`/
`调整尺寸`/`为空`/`前`/`后`/`数据`/`清空` 都覆盖到）。

## 已知边界

- 公开 API 是中文，**MSVC STL 内部实现与注释仍是英文**（为了跟随上游同步，
  见 `docs\标准库汉化\`）
- 成员函数表是**自动抽取**的，漏条目比错条目好：宁可漏，不可错
- 中文名不唯一可猜（`类型特征` 不是 `类型特性`）——遇到查不到的直接
  `grep` 中文头文件，或看这张表
